# ReFlow Engineering Constitution

This repository implements an evidence-first financial truth compiler for Razorpay AI Buildathon 2026 Track 04.

## Non-negotiable rules

1. Financial truth is deterministic. AI may propose adapters or investigate exceptions; it never marks money reconciled.
2. Money is signed integer paise with explicit currency. Never use float in the domain layer.
3. Raw source evidence is append-only and provenance is preserved.
4. Duplicate or reordered delivery must not duplicate value or change final truth.
5. Ambiguity fails closed into an explicit exception.
6. A zero residual is necessary but never sufficient proof of identity.
7. Hidden simulator truth must never be imported by production/reconciliation modules.
8. Every public metric must be generated by checked-in evaluation code.
9. Keep FAILURE_LOG.md and LIMITATIONS.md current when tests invalidate assumptions.
10. Do not add infrastructure (queues, caches, graph databases, model providers) until a measured need exists.

## Commands

```bash
python -m pip install -e '.[dev]'
python -m pytest
python -m ruff check .
python -m mypy src
```

`make check` runs the same validation suite.

## Package boundaries

- `reflow.domain`: dependency-light financial contracts and invariants.
- `reflow.simulator`: hidden financial-world generation and, later, observed-data corruption.
- later reconciliation packages may import `reflow.domain`, but production packages must never import `reflow.simulator.truth`.

## Development order

Follow the latest implemented checkpoint plus `docs/27_STRATEGIC_PAUSE_CURRENT_STATE_AND_REVISED_PLAN.md` for all post-Gate-12 sequencing. `docs/16_MASTER_BUILD_PLAN.md` remains historical/pre-review context. A later gate does not start merely to make the demo look complete while an earlier gate is red.
